Admin Guide

How to manage users and the platform

Adding users with birth details

  1. Go to Add User
  2. Fill in name, email, password and access level
  3. Optionally enter birth details (DOB, TOB, place, lat/lng/tz)
  4. If birth details are left empty, the user will be prompted to fill them on first login via the Complete Profile screen in the app
  5. Click Create User and share credentials with the user

Editing a user's birth details

  1. Go to All Users
  2. Click Edit next to any user
  3. Update birth date, time, place and coordinates in the Birth Details section
  4. Click Save Changes — the app reflects the update on next login

Changing access levels

  1. Go to All Users → Edit
  2. Change Access Level: Free → Premium → Admin
  3. Save — user gets new access on next app launch

Push notifications

  1. Go to Push Notifications
  2. Select target audience and enter title + message
  3. Optionally add a deep link (e.g. jyotish://horoscope)
  4. Click Send — shows count of users reached
  5. Users must have opened the app at least once to receive push
